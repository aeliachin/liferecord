## 上传 GitHub Pages

1. 解压压缩包
2. 把整个文件夹内容上传到 GitHub 仓库
3. 在仓库 `Settings -> Pages`
4. 选择 `Deploy from a branch`
5. Branch 选 `main`，目录选 `/root`
6. 保存后等待几分钟
